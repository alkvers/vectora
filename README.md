The website is fully responsive across all devices:

| Device | Breakpoint | Layout |
|--------|------------|--------|
| 📱 Mobile | `< 576px` | Single column, hamburger menu |
| 📱 Tablet | `576px - 768px` | 2-column grid |
| 💻 Laptop | `768px - 1024px` | 2-3 column grid |
| 🖥️ Desktop | `> 1024px` | Full layout with all effects |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server required — works with static file hosting

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/alkvers/vectora.git
   ```

2. **Navigate to the directory**
   ```bash
   cd vectora
   ```

3. **Open in browser**
   ```bash
   # Simply open index.html
   open index.html        # macOS
   xdg-open index.html    # Linux
   start index.html       # Windows
   ```

4. **Or use a local server** (optional)
   ```bash
   # Using Python
   python -m http.server 8000

   # Using Node.js
   npx serve

   # Using PHP
   php -S localhost:8000
   ```

5. **Visit** `http://localhost:8000`

## 🛠️ Customization

### Change Colors
Edit the CSS variables in `styles.css` or inline `<style>`:
```css
:root {
    --primary: #6C63FF;      /* Main color */
    --secondary: #FF6B9D;    /* Secondary color */
    --accent: #00D4AA;       /* Accent color */
    --bg: #0a0a1a;           /* Background */
}
```

### Change Logo Text
Find and replace in `index.html`:
```html
<!-- Change this -->
<div class="nav-logo">"^ Vectora</div>

<!-- To your logo -->
<div class="nav-logo">Your Logo</div>
```

### Update Contact Info
```html
<!-- WhatsApp -->
<a href="https://wa.me/YOUR_NUMBER">

<!-- Email -->
<!-- Change in FormSubmit action -->
action="https://formsubmit.co/YOUR_EMAIL"
```

### Add New Service
Copy an existing service card and modify:
```html
<div class="service-card glass-card" data-category="your-category">
    <div class="service-icon">🎯</div>
    <h3>Your Service</h3>
    <p>Description here</p>
</div>
```
